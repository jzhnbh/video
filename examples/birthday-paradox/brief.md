## direction

- 深蓝黑底 `#0A0A1E`，全片一套配色。
- 五区布局：左上 `@登风` / 顶标签带 / 中央 365 格「生日旅馆」 / y≈70% 注释 / y≈87% 中英双语字幕。
- 片名卡 13–20s：`VIBE知识大赏` + 金色衬线《同一天》+ 副题「23个人里，为什么总有人同一天生日？」/ `The Day We Share`。
- 每句 ≤20 字，停留 ≥2.5s；英文逐句意译。
- 转场从内容里长出来：文献里的迷你格阵 → 推近成整屏格阵；整屏格阵 → 缩成 1000 次模拟里的第一间房；一个金点 → 长成概率曲线；23 个点 → 长成 253 条连线。
- 禁止：居中大字+渐变、满屏小字、粒子爆炸、模板感。

## explanation

- 核心比喻只用一个：**一年是一面 365 格的「生日旅馆」墙，每个人是一张随机落进格子的纸卡**。后面所有概念都用它造句：落格、撞格、对数、同一间房。
- 观众上礼拜经历过的场景：班里/群里/婚礼上「又有人同一天生日」。
- 尺子：右侧一条 0–100% 的概率表，50% 处一条金线。全片拿它量 23 人（50.7%）、22 人（47.6%）、30 人（70.6%）、70 人（99.9%）、「和我同一天」（5.9%）。
- 约 1/5 的句子不配新画面：提问、命名、结论、片名回声。已在分镜表标注。

## 声音方案（回答「配音怎么配」）

1. **A 无配音（默认，推荐）**：完全符合风格 DNA，字幕承担叙事，BGM 撑情绪。成片即本仓库标准工作流。
2. **B 机器配音**：用 `edge-tts` 生成中文旁白（如 `zh-CN-YunxiNeural` / `zh-CN-XiaoxiaoNeural`），我再做逐句对齐、降噪、与 BGM 混音，BGM 降到约 -20 LUFS。**不需要你找人**，但需要允许我 `pip install edge-tts` 并联网调用。
3. **C 真人配音**：你给我一条人声轨（整轨 WAV/MP3 即可，能按句分段更好），我按 `script.md` 的时间轴对齐、修气口、混音。**需要你提供**；不用你找专业棚，手机安静环境录也可，但噪声大时我会先做降噪。

> 配音版建议把字幕改成「精简版」（保留关键词，不逐字重复人声），否则观众会「听一遍 + 读一遍」。本示例先按 A 做；要 B/C 的话我再出第二版。
