# 分镜表 · 《同一天》 / The Day We Share

## 0. 一页设计

| 项 | 定稿 |
|---|---|
| 一句话论点 | 23 个人里「任意两人同一天」的概率已经过半；直觉错在只数了「和我同一天」。 |
| 核心形象 | **一年是一面 365 格的「生日旅馆」墙，每个人是一张随机落进格子的纸卡。** 全片只用一个比喻。 |
| 那把尺子 | 右侧 0–100% 概率表，50% 处一条金线；量 23 人（50.7%）、22 人（47.6%）、30 人（70.6%）、70 人（99.9%）、「和我同一天」（5.9%）。 |
| 常驻元素 | 左上 `@登风`；顶中章节标签；右上/右侧概率表（40s 后常驻）；底部双语字幕带。 |
| 复用的画面 | 365 格墙（钩子/文献/首试/千次模拟）；23 张纸卡；23 节点图；概率表。 |
| 金色 `#C9A96A` | 碰撞、答案、被点亮的数。 |
| 冰蓝 `#7FA6C8` | 普通日期、普通人、已落格。 |

| 灰 `#8A8AA0` | 注释、英文、出处。 |

## 1. 转场设计

| 从 → 到 | 手法 | 内容怎么长出下一步 |
|---|---|---|
| 钩子 → 片名卡 | 压暗 | 两格碰撞的金光留在暗里，成为片名卡背景的两颗金点。 |
| 片名卡 → 1939 文献 | 卡片盖上来 | 一张做旧论文从下方升起，盖住星点。 |
| 文献 → 整屏 365 格 | 推近穿过 | 镜头钻进文献右下角的迷你格阵，格阵放大成整屏。 |
| 首试 → 1000 次模拟 | 缩小 + 留一个点 | 整屏格阵缩成「第 1 间房」，其余 999 间房在它周围长出来。 |
| 1000 间房 → 概率曲线 | 留一个点 | 第 510 间金房飞成曲线上的第一个金点，曲线从它生长。 |
| 曲线 → 253 对连线 | 变形 | 曲线上的 23 个采样点脱离坐标轴，围成一圈变成 23 个人。 |
| 连线 → 现实三连 | 收进胶片带 / 同屏换内容 | 23 节点图折成三张场景卡，并排出现。 |
| 现实三连 → 收尾卡 | 压暗 | 三张卡收成一颗金点，暗场里浮出片名与引用。 |

## 3. 分镜自检

- **停住/亮字类**：第 3、9、11、19、22、27、33、35、39 拍，共 9/39 ≈ 23%，接近「每五句一句不配新画面」。
- **遮住字幕只读画面**：钩子看得到「23 人落进 365 格、两格相撞」；中段看得到「1000 间房、510 间金、曲线过半、253 条线、22 条红线」；结尾看得到「教室/群聊/婚礼同一版式」。三问都能答。
- **核心比喻回场**：365 格墙出现在钩子、文献、首试、千次模拟、结尾；23 张纸卡出现在钩子、规则、首试、节点图。
- **反转层数**：第一层 23 人过半（77–79.5s）；第二层 253 对 vs 22 对（90–110s）；第三层 生活三连（110–120s）。
- **悬念**：钩子问「为什么过半」，97.5–110s 用「你只数了 22 对」解开。
- **读数**：概率表从 40s 起常驻，量过 23/22/30/70/5.9/50.7 六个数。
- **数字纪律**：每个数都来自 `NOTES.md`；模拟标「模拟」，文献标「图为示意」，曲线标「理论曲线」。
- **未决**：作者署名暂用 `@登风`；配音方案待用户选 A/B/C。
